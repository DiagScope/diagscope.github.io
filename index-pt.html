Datadog, Grafana e New Relic só conseguem mostrar os sinais que o seu código realmente produziu. Se o log, a métrica ou o contexto nunca foram escritos, nenhum dashboard vai inventá-los na hora do incidente.

  • 02 Uma falha vira um resultado que parece normal, e a causa original desaparece junto.
  • 03 Uma mensagem Kafka é enviada, mas ninguém verifica se o broker confirmou o recebimento.
  • 04 Um ID de pagamento vira tag de métrica — e sua conta de observabilidade infla junto.

Como funciona

O DiagScope roda antes de Datadog, Grafana ou New Relic verem qualquer sinal — direto no seu código-fonte, no seu editor ou no seu CI.

Aponte pra um projeto

Um repositório Maven por execução. Sem servidor, sem credencial, nenhum código sai da sua máquina.

Ele encontra seus pontos de entrada

Endpoints REST, listeners Kafka, jobs agendados — os lugares onde um fluxo de verdade começa.

Ele segue o fluxo

Chamadas locais, poucos níveis de profundidade. Quando não tem certeza, ele diz — nunca disfarça um chute de fato.

Você recebe um relatório

O que está faltando, onde, e o quanto o DiagScope confia nisso — arquivo, linha, e uma sugestão concreta.

O que ele verifica hoje

A Fase 1 é propositalmente pequena — quatro verificações escolhidas porque quase nunca são questão de estilo, e quase sempre valem a pena corrigir.

Catch silencioso

Uma exceção desaparece

Capturada e nunca logada, propagada, ou tratada de algum jeito. Aconteça o que acontecer, ninguém vai saber.

catch (Exception e) { }
Falha convertida silenciosamente

Uma falha parece um sucesso

A exceção vira false, null, ou Optional.empty() — e a causa original desaparece junto.

catch (Exception e) { return null; }
Envio ao Kafka ignorado

Publica, e torce

O método retorna antes do broker confirmar, sem nenhum callback observando falha de entrega.

kafkaTemplate.send(topic, event);
Tag de métrica de alta cardinalidade

Um ID único vira tag de métrica

paymentId, um UUID, um request ID — usar isso como tag de métrica explode a cardinalidade lá na frente.

.tag("paymentId", id.toString())
Isso ainda é fase inicial. A Fase 1 existe pra testar uma coisa só: se esses achados se sustentam em código real, com poucos falsos positivos. Instrumentação por aspectos, comparação com dashboard do Grafana, e fluxos entre serviços estão planejados — mas só se essa primeira aposta, menor, se provar primeiro.
