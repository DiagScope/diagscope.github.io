Some failures don't fail loud enough.

Datadog, Grafana and New Relic can only show you the signals your code actually produced. If the log, the metric or the context was never written, no dashboard will conjure it back during an incident.

  • 01 An exception is caught and quietly discarded — no log, no metric, no rethrow.
  • 02 A failure is converted into a normal-looking result, and the original cause goes with it.
  • 03 A Kafka message is sent, but nothing is watching whether the broker ever confirmed it.
  • 04 A payment ID ends up as a metric tag — and your observability bill inflates with it.

How it works

DiagScope runs before Datadog, Grafana or New Relic ever see a signal — directly on your source, in your editor or your CI.

Point it at a project

One Maven repository per run. No server, no credentials, no code leaves your machine.

It finds your entry points

REST endpoints, Kafka listeners, scheduled jobs — the places a real flow begins.

It follows the flow

Local calls, a few levels deep. When it can't be sure, it says so — never a guess dressed up as fact.

You get a report

What's missing, where, and how confident DiagScope is — file, line, and a concrete suggestion.

What it checks today

Phase 1 is deliberately small — four checks chosen because they're almost never a matter of style, and almost always worth fixing.

Silent catch

An exception disappears

Caught and never logged, propagated, or otherwise acted on. Whatever happened, no one will know.

catch (Exception e) { }
Silent failure conversion

A failure looks like success

The exception becomes false, null, or Optional.empty() — and the original cause goes with it.

catch (Exception e) { return null; }
Kafka send ignored

Publish, and hope

The method returns before the broker confirms, with no callback watching for delivery failure.

kafkaTemplate.send(topic, event);
High-cardinality tag

A unique ID becomes a metric tag

paymentId, a UUID, a request ID — tagging a metric with it explodes cardinality downstream.

.tag("paymentId", id.toString())
This is early. Phase 1 exists to test one thing: whether these findings hold up on real code, with few false positives. Aspect-oriented instrumentation, Grafana dashboard comparison, and cross-service flows are planned — but only if this first, smaller bet proves itself first.
